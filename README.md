# StudyPet

Aplikasi jadual harian percuma untuk pelajar sekolah rendah dan menengah merancang masa belajar di rumah.
Ada dua bahasa: Bahasa Melayu dan English (tekan butang bahasa dalam app).

> A free daily study-schedule app for primary and secondary school students. Available in Malay and English.

## Fungsi

- Isi profil: nama, tahap, subjek, jam belajar sehari dan tarikh peperiksaan
- Dapat jadual belajar harian
- Pemasa sesi belajar (25 minit setiap sesi)
- Kumpul XP dan naik level semasa belajar
- Gambar profil boleh dimuat naik sendiri
- Data disimpan dalam browser peranti anda sahaja (tidak dihantar ke mana-mana pelayan)

## Cara guna

Buka laman web StudyPet di GitHub Pages, atau muat turun projek ini dan buka `index.html` dalam browser.

## Fail dalam projek

| Fail | Fungsi |
| --- | --- |
| `index.html` | Rangka halaman |
| `style.css` | Rupa dan warna |
| `script.js` | Logik app |
| `logo.png` | Logo dan ikon tab |

Semua fail mesti berada dalam folder yang sama.

## Privasi

- Data profil dan kemajuan disimpan dalam `localStorage` browser anda. Jika anda kosongkan data browser, data itu hilang.
- Halaman ini menggunakan Google Analytics (`googletagmanager.com`) untuk mengira jumlah pengunjung.
